Token safety scanner

Solana mint or EVM token address. Evidence from Solana RPC, RugCheck, GoPlus, honeypot.is, DexScreener and Jupiter, run in your browser. Policy . A pass is not a buy.

Try: BONK · USDC (has authorities) · PEPE (ETH)

New-pair radar

Newest pools from GeckoTerminal merged with DexScreener profiles and boosts. Snapshot is refreshed by GitHub Actions; press Live to fetch from your browser.

PnL and UK Capital Gains

Paste trades as CSV: time,side,asset,qty,total,fee[,quoteAsset,quoteQty,note]. total is the GBP value at the time of the trade (HMRC requires sterling). Runs entirely on this device. Arithmetic aid, not tax advice.

Launch checklist

For teams launching a token, or buyers checking a team's claims. Auto items come from a live scan; manual items are saved on this device.

Portfolio

Holdings are stored only in this browser. Prices from Jupiter; GBP via Chainlink GBP/USD (Blockchains/onetouchswitch-bridge). Wallet import needs an RPC that allows getTokenAccountsByOwner from browsers (free public RPCs block it) — paste your own RPC URL.

Static JSON API, SDK and MCP

All endpoints are static files on GitHub Pages with Access-Control-Allow-Origin: *, rebuilt by GitHub Actions.

    Use the SDK from any site (e.g. memecoin.grok.me)

    import { scanToken, radar, ukCgt } from 'https://blockchains.github.io/memecoin-markets/lib/index.js';
const s = await scanToken({ address: 'DezXAZ8z7PnrnRJjz3wXBoRgixCa6xjnB7YaB1pPB263' });
console.log(s.verdict, s.checks);

    MCP (Grok, Cursor, Claude, VS Code)

    npx -y github:Blockchains/memecoin-markets memecoin-mcp
